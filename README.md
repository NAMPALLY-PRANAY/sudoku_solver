# Sudoku Solver GUI with Tkinter

This project is a Sudoku solver implemented using Python's `tkinter` library for the graphical user interface (GUI). The application allows users to input a Sudoku puzzle and solve it using an algorithm. It supports different grid sizes: 3x3, 6x6, 9x9, and 16x16 grids.

## Features

- **Grid Selection**: Choose from 3x3, 6x6, 9x9, or 16x16 grids for different Sudoku difficulty levels.
- **Interactive Interface**: The user can click on the grid to enter numbers.
- **Solve Function**: The solver algorithm will find the solution to the given puzzle.
- **Clear Function**: Reset the grid and start over with a new puzzle.
- **Responsive Design**: The layout adapts to different grid sizes.

## Requirements

- Python 3.x
- Tkinter (usually comes pre-installed with Python)
- Basic understanding of Sudoku puzzles

## Installation

1. Clone this repository:

```bash
git clone [https://github.com//sudoku-solver-gui.git](https://github.com/NAMPALLY-PRANAY/sudoku_solver)
```

2. Navigate to the project directory:

```bash
cd sudoku-solver-gui
```

3. Run the application:

```bash
python sudoku_gui.py
```

## How It Works

1. **Input the puzzle**: Enter numbers in the grid. Empty cells should be left blank.
2. **Solve the puzzle**: Click the "Solve" button to find the solution.
3. **Clear the grid**: Click the "Clear" button to reset the grid.
